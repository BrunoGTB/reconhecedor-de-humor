# Reconhecedor de Humor

## 1. Descrição do Projeto

O **Reconhecedor de Humor** é um projeto desenvolvido em Python com o objetivo de identificar expressões faciais associadas a diferentes emoções e detectar sinais visuais que possam indicar sonolência ou olhos fechados.

O sistema utilizará imagens capturadas por uma webcam ou fornecidas por uma interface de vídeo para analisar as características faciais de uma pessoa e estimar seu estado emocional aparente.

## 2. Objetivos

* Identificar emoções a partir de expressões faciais.
* Detectar sinais visuais de sonolência, como olhos parcialmente fechados.
* Identificar quando os olhos permanecem fechados, indicando que a pessoa pode estar dormindo.
* Explorar técnicas de visão computacional e aprendizado de máquina aplicadas à análise facial em tempo real.

## 3. Funcionamento

O sistema receberá imagens de uma webcam ou de outra fonte de vídeo e realizará a análise das características faciais detectadas.

Com base nessas informações, o algoritmo produzirá estimativas das emoções aparentes e dos sinais visuais de sonolência, conforme os critérios definidos durante o desenvolvimento do projeto.

## 4. Limitações

A identificação de emoções será baseada exclusivamente em características visuais da face. Portanto, os resultados representarão estimativas das expressões aparentes, e não necessariamente o estado emocional real da pessoa.

Da mesma forma, o sistema não será capaz de determinar com certeza se uma pessoa está dormindo. A análise dos olhos poderá indicar sinais compatíveis com sonolência ou olhos fechados, mas esses indicadores, isoladamente, não são suficientes para confirmar um estado de sono.

O projeto não utilizará outros indicadores fisiológicos ou de consciência que permitam uma avaliação mais abrangente dessas condições.

## 5. Finalidade

Este projeto tem finalidade exclusivamente educacional, servindo como estudo prático de Python, visão computacional e técnicas de aprendizado de máquina aplicadas à análise de expressões faciais e à detecção de sinais visuais de sonolência.
